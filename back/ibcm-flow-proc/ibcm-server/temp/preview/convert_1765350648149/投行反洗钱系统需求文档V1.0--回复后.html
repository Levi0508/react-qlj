2. 详细业务功能需求

本章将介绍开发细节，适合于开发人员与业务人员阅读。

2.1.需求背景

投行大数据平台系统，投资银行业务委员会对于投行业务开展中客户及项目数据，资讯及舆情数据，工商信息数据等不同来源数据的查询及订阅需求；提供项目清单信息填报，邮件提醒，数据推送（包括自营&衍生品，研究所，机构，香港国际，权益客需）等功能；提供投行反洗钱客户信息维护，信息变更/审核流程，到期提醒邮件及流程，风险核查流程，与法律合规部反洗钱监测分析系统进行数据交互。

根据 XY 公司合并进度，在业务整合时对应发生系统变更、在法切阶段由于统一数据报送对应发生系统变更，在系统内切阶段对应产生各类项目需求。

2.2.投行反洗钱系统

2.2.1.系统流程

1. 系统对客户证件信息是否到期进行监测，若即将到期需要自动发送邮件提醒。（客户及其法定代表人或负责人、受益所有人的身份证件）

2. 原系统进行失效处理通过邮件提醒，现有系统需要改造为若项目组所有项目完结，推送流程至全链接系统提醒客户维护人，客户维护人在全链接系统点击同意后，申请终止客户自动发送邮件提醒给合规人员，合规人员收到邮件后在反洗钱系统进行【失效】操作。

2.2.2.1.客户信息检索

进入页面前，弹窗提示用户输入公司名称或统一社会信用代码进行检索（括号需使用全角），如下图

  • 若系统中不存在该客户信息，则弹窗提示【客户未填报，是否需要新增】；

用户点击【确认】后，弹出新增客户类型供用户选择

  • 若系统中存在客户信息，则弹窗提示【XX客户已存在，是否需要修改客户信息】，点击“是”则跳转至客户基本信息表界面。

2.2.2.2.主体信息填报

注：主体信息填报页所有字段不做必填校验，在【反洗钱客户基本信息】提交页面做必填校验。

2.2.2.2.1.客户基本信息

  • 机构客户：

    • 客户名称：支持用户手动输入；也支持基于工商信息匹配，自动调用企查查接口。

    • 办公住所：省市区下拉选择，详细地址手动填充/选择工商信息匹配，自动根据省/市/行政区（Area:Procince/City/Country?还是Address注册地址）拆分填充。注：在后续客户基本信息提交验证字段必填时：若注册国家地区为境内，则字段省市区详细地址均必填；若注册国家地区为境外，则字段只显示详细地址

    • 注册国家地区：下拉选择/企查查自动填充（Address注册地址？）注：若历史数据证件类型为营业执照，则该字段默认为CHN

    • 注册资本金币种：下拉选择

    • 注册资本金：手动填充/企查查自动填充（对应注册资本）

    • 行业分类：下拉选择

    • 联系电话：手动填充

    • 成立日期：日期控件选择/企查查自动填充

    • 证照类型：下拉选择

    • 证照号码：手动填充

    • 证照有效期：包含证件有效期起始与证件有效期截止两个字段；日期控件选择/企查查自动填充（对应营业期限始和营业期限止）

    • 附件信息：支持pdf、word、excel、png、jpg等



  • 个人客户（字段）：

    • 姓名：手动填充

    • 性别：选择

    • 身份证件类型：下拉选择

    • 证件号码：手动填充

    • 国籍：下拉选择

    • 出生年月：日历控件选择

    • 证件有效期：包含证件有效期起始与证件有效期截止两个字段

    • 身份证件地址：手动填充

    • 联系地址：省市区下拉选择，详细地址手动填充

    • 联系电话：手动填充

    • 年收入（单位：人民币）手动填充

    • 职业分类：下拉选择

2.2.2.2.2.主体登记

  1. 机构主体登记

点击机构主体登记旁的加号按钮后，出现下图所示弹窗

  • 名称：手动填充

  • 国籍：下拉选择

  • 证照类型：下拉选择

  • 证照号码：手动填充

  • 证照有效期：包含证件有效期起始与证件有效期截止两个字段；日期控件选择

  • 是否政府部门：单选（注：若是政府部门，后续必填校验只需要验证名称必填）

  • 请选择关联主体信息标签：只能从控股股东/实际控制人中选择

  • 附件证明材料：支持pdf、word、excel、png、jpg等

用户录入信息后，在主界面生成一条记录。该记录支持修改与删除。

  1. 自然人主体登记

  • 姓名：手动填充

  • 国籍：下拉选择

  • 证照类型：下拉选择

  • 证照号码：手动填充

  • 证照有效期：包含证件有效期起始与证件有效期截止两个字段；日期控件选择

  • 出生年月日：日期控件选择

  • 附件证明材料：支持pdf、word、excel、png、jpg等



用户录入信息后，在主界面生成一条记录。该记录支持修改与删除。

2.2.2.2.3.附件管理

支持用户通过树形目录上传文件集：用户下载树形结构附件模板后，在本地按照树形目录结构保存好相应的附件，保存好的文件夹上传至系统后，系统自动解析目录，相应保存在系统的树形列表中。
